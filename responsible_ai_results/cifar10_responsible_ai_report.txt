RESPONSIBLE AI INTERPRETATION
-----------------------------------------------------------------
This experiment measures differences in predictive performance and probability reliability across CIFAR-10 object categories.

Class-wise differences may indicate that a model does not perform equally well across all object categories. These differences should be investigated before deploying a model in settings where errors have meaningful consequences.

CIFAR-10 does not provide demographic attributes. Therefore, this experiment does not establish demographic fairness, protected-group fairness, or the absence of societal bias.

One-vs-rest ECE measures calibration separately for each class using class probabilities and binary class membership. It depends on binning choices and should not be interpreted as a complete measure of calibration.

The one-vs-rest Brier score is the mean squared error between a class probability and its binary target. Lower values indicate better probabilistic predictions for that class.

LIMITATIONS
-----------------------------------------------------------------
1. Results apply to the CIFAR-10 test distribution.
2. Object categories are not demographic groups.
3. Class-wise metrics do not explain the causes of performance differences.
4. Calibration results depend on the chosen number of bins.
5. No out-of-distribution or real-world deployment evaluation is included.
6. No causal fairness conclusions can be drawn.
7. Grad-CAM visual explanations are not causal proof of model reasoning.

FUTURE RESEARCH

3. Investigate class-specific data augmentation.
