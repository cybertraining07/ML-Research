CIFAR-10 ADVERSARIAL DEFENSE EVALUATION
=======================================================

Evaluation methodology:
Clean evaluation: 10,000 test images
FGSM evaluation: 10,000 test images
PGD evaluation: 2,000 balanced test images
FGSM epsilon: 8/255
PGD epsilon: 8/255
PGD step size: 2/255
PGD iterations: 10

Corrected evaluation results:

Model: Baseline CNN
Clean Accuracy (%): 72.4
FGSM Accuracy (%): 3.39
FGSM Attack Success Rate (%): 95.37
PGD Accuracy (%): 0.05
PGD Attack Success Rate (%): 99.93

Model: FGSM Defense
Clean Accuracy (%): 46.5
FGSM Accuracy (%): 20.72
FGSM Attack Success Rate (%): 62.17
PGD Accuracy (%): 12.65
PGD Attack Success Rate (%): 78.76

Model: PGD Defense
Clean Accuracy (%): 48.85
FGSM Accuracy (%): 19.12
FGSM Attack Success Rate (%): 63.36
PGD Accuracy (%): 12.15
PGD Attack Success Rate (%): 77.51

Model: Mixed FGSM Defense
Clean Accuracy (%): 66.6
FGSM Accuracy (%): 20.2
FGSM Attack Success Rate (%): 69.95
PGD Accuracy (%): 8.9
PGD Attack Success Rate (%): 86.85

Research findings:
- FGSM Defense achieved the highest adversarial accuracy against both tested attacks.
- Mixed FGSM Defense preserved more clean accuracy than the adversarial-only defenses.
- The baseline CNN was highly vulnerable to the tested adversarial attacks.

Limitations:
- PGD results use a balanced 2,000-image subset.
- Clean and FGSM results use all 10,000 test images.
- Results apply only to the tested attacks and settings.
- Empirical robustness does not establish universal robustness.
- Each model was evaluated from one training run.
